# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** action in the repository's Security tab to contact the maintainers privately. Include the affected version or commit, steps to reproduce, and any known impact. Please allow time for a fix before sharing details publicly.

## Supported versions

Until the first release, security fixes are handled on the default branch. After releases begin, the supported versions will be documented here.
